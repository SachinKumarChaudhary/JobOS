## Code of Conduct

This project follows the [Contributor Covenant](CODE_OF_CONDUCT.md). By participating, you agree to uphold its standards.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/JobOS.git`
3. Create a branch: `git checkout -b my-feature-branch`

## How to Contribute

### Report a Bug

Open a [Bug Report](.github/ISSUE_TEMPLATE/bug_report.md) and include:
- Steps to reproduce
- Expected vs actual behavior
- Screenshots if applicable
- Environment details (OS, browser, version)

### Suggest a Feature

Open a [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md) describing:
- The problem you're solving
- How the feature would work
- Any alternatives you've considered

### Submit Code

1. Ensure an issue exists for what you're working on
2. Comment on the issue to claim it
3. Follow the [Pull Request Guidelines](#pull-request-guidelines)

## Pull Request Guidelines

- Keep PRs focused — one feature/fix per PR
- Write clear, descriptive commit messages
- Update documentation (README, comments) as needed
- Ensure no breaking changes without discussion
- Reference the issue number in your PR description (e.g. `Closes #12`)
- Request review from maintainers

## Style Guide

- Follow the language/framework conventions used in the project
- Keep functions small and single-purpose
- Use meaningful variable and function names
- Write comments only where intent isn't obvious

## Getting Recognition

Contributors are recognized via [All Contributors](https://allcontributors.org/). Once your PR is merged, a maintainer will add you using:

```
@all-contributors please add @username for code, doc, design
```

You'll be added to the README as a recognized contributor.
