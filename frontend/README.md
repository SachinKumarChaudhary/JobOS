# 🚀 GotJobAlert

GotJobAlert is a job portal web application designed to help students and job seekers discover internships, fresher jobs, and career opportunities through a clean and responsive interface.

## 📌 Project Status
🚧 Currently in Development

## ✨ Features
- Responsive UI
- Modern Dashboard
- Job Listings
- Search & Filter
- Resume Section
- Notifications
- User Authentication (Planned)
- Backend API Integration (Planned)

## 🛠️ Tech Stack
