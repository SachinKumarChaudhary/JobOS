# JobOS

[![GitHub](https://img.shields.io/github/license/SachinKumarChaudhary/JobOS?style=flat-square)](LICENSE)

> Track jobs, tailor resumes, ace interviews — all in one place.

JobOS helps job seekers organize their entire job search: discover opportunities, track applications with status, generate tailored resumes for each role, and prepare for interviews with structured notes.

## Features

- **Job Tracking** — Save and organize job listings with status (saved, applied, interview, offer, rejected)
- **Custom Resumes** — Create and store tailored resumes for each application
- **Interview Prep** — Track interview stages, questions, and notes per role
- **Dashboard** — Visual overview of your job search pipeline
